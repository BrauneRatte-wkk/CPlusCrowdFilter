# CPlusCrowdFilter（混雑時のフィルター）

Ultima Online Enhanced Client のカスタム UI「CLifeUI」に足して使う、非公式の追加機能です。

**CLifeUI が必須です。** CLifeUI のフォルダの中に置き、CLifeUI のモジュールの後に読み込まれて働く作りなので、CLifeUI を入れていない状態や、ほかのカスタム UI では動きません。先に CLifeUI を入れて、動くことを確かめてから入れてください。CLifeUI は、作者様の公式ページ（<https://uo.clife.work/uosa-custom-ui-clifeui/>）の手順で入れてください。

大規模なイベントのように人が多い場所で、画面に出る物を減らしたり、自分を見つけやすくしたりする機能の集まりです。どれもアイコンで ON／OFF でき、初めは OFF です（自分の頭上の窓の付け直しだけは、いつも働きます）。

**詳しい入れ方と使い方は、zip の中の `使い方.html` をブラウザで開いてください。**

## できること

- 味方ダメージ 表示切替: ON の間、味方（青ネーム）が受けたダメージの数字を出しません。自分と自分のペット・召喚のダメージは出します。
- オブハン フィルタ切替: ON の間、オブハン（物の名前の札）を、敵（灰・赤ネーム）と自分のペット・召喚だけにします。
- 頭上の詠唱 出し分け: 頭上に出る呪文の詠唱を、話した人で出し分けます（全員／自分とパーティ／自分だけ／全部隠す）。チャット欄はそのままです。
- 自分の矢印: ON の間、自分の頭の上に水色の矢印を出し続けます。
- 自分の頭上の窓の付け直し: リコールなどのあとに自分の発言や詠唱が頭上に出なくなることがあるのを、自分が話すたびに直します。

## このソフトがゲームに対してしないこと

- ゲームのクライアントを書き換えません。Enhanced Client が公式に用意しているカスタム UI の仕組みの中で動きます。
- ゲームのメモリを外から読んだり書いたりしません。
- ゲームとサーバの間の通信を、読んだり書き換えたりしません。このソフトからサーバへ何かを送ることもありません。
- ゲームの操作を自動で行いません。ボタンを押す・アイテムを使う・キャラクターを動かすといった操作はせず、画面に出す物を減らすことと、矢印を表示することだけをします。
- CLifeUI のファイルは書き換えません。フォルダを消せば、元の動きに戻ります。
- ファイルを書き出しません。保存するのは、各機能の ON／OFF だけです。

## 動く環境

- Ultima Online Enhanced Client（日本語のクライアントで確かめています）
- **CLifeUI（必須）**。公開されている版で確かめています
- Windows。追加で入れるものはありません

## 入れ方（要約）

1. `CPlusCrowdFilter-0.1.zip` を展開すると、`ClfMods\CPlusCrowdFilter` フォルダができます。
2. そのフォルダを、CLifeUI の `ClfMods` フォルダの中に、フォルダごと入れます。
3. ゲームを起動します（起動中なら、マクロで `script InterfaceCore.ReloadUI()` を実行して UI を読み直します）。
4. 行動ウィンドウの分類「CPlus」にある 4 つのアイコンのうち、使うものをホットバーに置きます。押すたびに切り替わり、頭の上とチャット欄に今の状態が出ます（どちらも自分の画面の表示だけで、ほかのプレイヤーには見えません）。

## アンインストール（要約）

1. 先にホットバーから、置いたアイコンを外します（残すと、押しても何も起きないアイコンになります）。
2. CLifeUI の `ClfMods\CPlusCrowdFilter` フォルダを消します。

ゲームの設定に残る値と、その置き場所は、`使い方.html` の「アンインストール」にあります。
