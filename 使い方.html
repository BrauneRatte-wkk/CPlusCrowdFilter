混雑時のフィルター 使い方

CLifeUI に足して使う、非公式の追加機能「CPlusCrowdFilter（混雑時のフィルター）」の入れ方と使い方です。

CLifeUI が必須です。CLifeUI のフォルダの中に置き、CLifeUI のモジュールの後に読み込まれて働く作りなので、CLifeUI を入れていない状態や、ほかのカスタム UI では動きません。先に CLifeUI を入れて、動くことを確かめてから入れてください。CLifeUI は、作者様の公式ページ（https://uo.clife.work/uosa-custom-ui-clifeui/）の手順で入れてください。

1. これは何か

大規模なイベントのように人が多い場所で、画面に出る物を減らしたり、自分を見つけやすくしたりする機能の集まりです。どれもアイコンで ON／OFF でき、初めは OFF です（自分の頭上の窓の付け直しだけは、いつも働きます）。

機能すること
味方ダメージ 表示切替ON の間、味方（青ネーム）が受けたダメージの数字を出しません。自分と自分のペット・召喚のダメージは出します。
オブハン フィルタ切替ON の間、オブハン（物の名前の札）を、敵（灰・赤ネーム）と自分のペット・召喚だけにします。
頭上の詠唱 出し分け頭上に出る呪文の詠唱を、話した人で出し分けます（全員／自分とパーティ／自分だけ／全部隠す）。
自分の矢印ON の間、自分の頭の上に水色の矢印を出し続けます。人の多い所で自分を見失わないためのものです。
自分の頭上の窓の付け直しリコールなどのあとに自分の発言や詠唱が頭上に出なくなることがあるのを、自分が話すたびに直します。切り替えはありません。

画面の表示を変えるだけです。ゲームの操作を自動で行うことはありません（安全について）。

2. しくみ（CLifeUI との関係）

混雑時のフィルターは、CLifeUI のファイルを書き換えません。CLifeUI の横に別のフォルダとして置き、ゲームの標準の UI の関数のうち、ダメージの数字・頭上の文・オブハンの一覧の 3 つに、外側から薄い処理をかぶせます。ダメージの数字と頭上の文は、CLifeUI（ClfDamageMod・ClfTextParse）も自分の処理に差し替えているので、フィルターはその外側に入ります（そのために、CLifeUI のモジュール ClfCommon・ClfDamageMod・ClfTextParse より後に読み込まれるようにしてあります）。オブハンの一覧は、CLifeUI（ClfCommon）が札を作るたびに呼んで受け取る関数で、CLifeUI はこれを差し替えません。フィルターが絞った一覧を、CLifeUI がそのまま受け取ります。

ほかに、行動ウィンドウでは、CLifeUI がアイコンを足したあとに、分類「CPlus」と 4 つのアイコンを足します。CLifeUI のアイコンはそのままです。

CLifeUI を自分で変えているとき

  • フィルターは、UI を読み込んだときに、その時点の関数の外側にかぶさります。ClfCommon・ClfDamageMod・ClfTextParse を自分で書き換えていても、ダメージの数字と頭上の文は、関数の名前が同じなら書き換えた処理の外側にかぶさり、OFF の間はその処理へそのまま渡します。オブハンは、札を作る処理が一覧の関数を名前で呼んでいれば、絞った一覧が渡ります。
  • ゲームの途中で、別の改造が同じ関数を差し替え直すと、フィルターが外れて働かなくなることがあります。
  • かぶせる相手の関数が見つからないときは、チャットに CPlusCrowdFilter : hook missing (…) と出て、その機能だけが働きません。

3. 動く環境

ゲームUltima Online Enhanced Client。日本語のクライアントで確かめています（文言は日本語と英語があります）。
カスタム UICLifeUI（必須）。公開されている版で確かめています。CLifeUI のフォルダの中に置き、CLifeUI のモジュール（ClfCommon・ClfDamageMod・ClfTextParse）の後に読み込まれる作りなので、CLifeUI が無いと動きません。
Windowsゲームが動く Windows なら、追加で入れるものはありません。

4. 入れ方

  1. zip を展開します。CPlusCrowdFilter-0.1.zip を展開すると、ClfMods\CPlusCrowdFilter フォルダができます。
  2. CLifeUI の中に入れます。ClfMods\CPlusCrowdFilter フォルダを、CLifeUI の ClfMods フォルダの中に、フォルダごと入れます。 
    C:\Program Files (x86)\Electronic Arts\Ultima Online Enhanced\
  UserInterface\
    <CLifeUI のフォルダ>\    ← 名前は自由（公式の手順では ClifeUI-master）
      ClfMods\
        ClfCommon\          ← CLifeUI のもの
        …
        CPlusCrowdFilter\   ← ここに入れる（フォルダごと）
    Program Files の下なので、コピーのときに管理者の確認が出ます。
  3. ゲームを起動します。起動中なら、UI を読み直します（マクロで script InterfaceCore.ReloadUI()）。
  4. アイコンをホットバーに置きます。行動ウィンドウの分類「CPlus」に、4 つのアイコンがあります。使うものをホットバーに置きます。
    アイコンの絵の文字名前
    青ダ／切替味方ダメージ 表示切替
    オブハン／切替オブハン フィルタ切替
    詠唱／表示頭上の詠唱 出し分け
    自分／矢印自分の矢印
    家の記録（CPlusHomeRecord）も入れているときは、同じ「CPlus」の分類に並びます。

5. 使い方

アイコンを押すたびに切り替わり、頭の上とチャット欄に今の状態が出ます。どちらも自分の画面の表示だけで、ほかのプレイヤーには見えません。状態はキャラクターごとに保存され、ログインし直しても、UI を読み直しても続きます。

味方ダメージ 表示切替

  • 押すたびに ON／OFF。頭の上とチャット欄に「味方ダメージフィルタ: ON」「味方ダメージフィルタ: OFF」と出ます。
  • ON の間、ダメージを受けた相手の名前の色が青なら、その数字を出しません。頭の上の数字だけでなく、ダメージの一覧やチャットにも出ません。
  • 自分と、自分のペット・召喚が受けたダメージは、青でも出します。
  • 名前の色が分からない相手と、青以外（緑・灰・赤など）の相手のダメージは出します。

オブハン フィルタ切替

  • 押すたびに ON／OFF。頭の上とチャット欄に「オブハンフィルタ: ON」「オブハンフィルタ: OFF」と出ます。
  • ON の間、オブハン（Ctrl＋Shift などで出す、物の名前の札）を、生物のうち次のものだけにします: 自分のペット・召喚、名前が灰色の相手、名前が赤の相手。灰色でも、犯罪者（犯罪をして灰色になったプレイヤー）の札は出ません。
  • ほかの生物と、アイテム・死体の札は出ません。
  • オブハンを出しているときに切り替えると、その場で出し直します。

頭上の詠唱 出し分け

押すたびに、次の 4 つを順に巡ります。初めは OFF です。

状態頭上に出す詠唱押したときに出る文（頭の上とチャット欄）
OFF全員分（ふつうと同じ）詠唱: OFF
自分とパーティ自分と、パーティの仲間の分詠唱: 自分とパーティ
自分だけ自分の分詠唱: 自分だけ
全部隠す出しません（自分のも）詠唱: 全部隠す
  • 隠すのは、頭上に出る呪文の言葉だけです。呪文でない会話は、どの状態でも出ます。チャット欄には、どの状態でも全部出ます。
  • 出す相手に入らない人の詠唱は、ほかのプレイヤー・コンピュータの敵・ペットを区別せずに隠します。
  • ゲームの設定にある標準の「頭上の詠唱呪文を非表示」が入っていると、この切り替えに関係なく全員分が隠れます。そのときにアイコンを押すと、頭の上とチャット欄に「（標準の『頭上の詠唱呪文を非表示』が入っているので全部隠れます）」と添えて知らせます。
  • OFF 以外の状態でログインしたときは、チャットに今の状態が 1 行出ます。

自分の矢印

  • 押すたびに ON／OFF。頭の上とチャット欄に「自分の矢印: ON」「自分の矢印: OFF」と出ます。
  • ON の間、自分の頭の上に水色の矢印を出し続けます。リコールなどで場所が変わっても、2 秒以内に付け直して出し続けます。
  • 矢印は自分だけです。仲間やペットには付けません。
  • ログインの直後などで自分の位置が取れないときに ON にすると、チャットに「自分の矢印: 自分の位置が取れないので、今は出せません」と出ます。ON のままなので、位置が取れるようになれば出ます。
  • OFF の間は何もしません。

自分の頭上の窓の付け直し（切り替えなし）

リコールなどのあと、自分の発言や詠唱が頭上に出なくなり、UI を読み直すまで直らないことがあります。この機能は、自分が話すたびに頭上の窓を付け直して、これを防ぎます。いつも働いていて、切り替えはありません。ほかの人の頭上の窓には触りません。

マクロから使う

アイコンの代わりに、マクロに次の 1 行（script で始まる行）を書いても使えます。

機能マクロに書く行
味方ダメージ 表示切替script CPlusCrowdFilter.toggleDamage()
オブハン フィルタ切替script CPlusCrowdFilter.toggleHandles()
頭上の詠唱 出し分けscript CPlusCrowdFilter.cycleSpells()
自分の矢印script CPlusCrowdFilter.toggleSelfArrow()

6. 安全について

  • ゲームのクライアントを書き換えません。Enhanced Client が公式に用意しているカスタム UI の仕組みの中で動きます。
  • ゲームのメモリを外から読んだり書いたりしません。
  • ゲームとサーバの間の通信を、読んだり書き換えたりしません。このソフトからサーバへ何かを送ることもありません。
  • ゲームの操作を自動で行いません。ボタンを押す・アイテムを使う・キャラクターを動かすといった操作はせず、画面に出す物を減らすことと、矢印を表示することだけをします。
  • CLifeUI のファイルは書き換えません。ゲームの標準の UI の関数を外から包んで、表示する前に出すか出さないかを決めます。フォルダを消せば、元の動きに戻ります。
  • ファイルを書き出しません。保存するのは、各機能の ON／OFF だけです（ゲームの設定に残るもの）。

配布前の検査: 配る zip は、公開する前に ESET で検査しています。検査した日と検出エンジンの版、zip の SHA-256 は、GitHub のリリースの説明に書いてあります。

7. アンインストール

  1. 先にホットバーから、置いたアイコンを外します（残すと、押しても何も起きないアイコンになります）。
  2. CLifeUI の ClfMods\CPlusCrowdFilter フォルダを消します。次の起動から読み込まれません。

ゲームの設定に残るもの

次の値をゲームの設定に保存します。フォルダを消しても残りますが、読む物が無くなるので、ゲームの動きには影響しません。

キャラクターごとの設定のファイル: ドキュメント\EA Games\<ゲームの名前>\User Data\<アカウント>\<シャード>\<キャラクター名>（拡張子の無い XML のファイル）

ファイルの中の場所名前中身
CharacterSettings → Options → UIVariables の BoolVarCPlusCrowdFilterDamage味方ダメージ 表示切替の ON／OFF
同じ所の BoolVarCPlusCrowdFilterHandlesオブハン フィルタ切替の ON／OFF
同じ所の NumberVarCPlusCrowdFilterSpellMode頭上の詠唱 出し分けの状態（0 OFF・1 自分とパーティ・2 自分だけ・3 全部隠す）
同じ所の BoolVarCPlusCrowdFilterSelfArrow自分の矢印の ON／OFF
CharacterSettings → Interface → Hotbars の UserActionid が 6015・6016・6033・6034ホットバーに置いたアイコン（ホットバーから外せば消えます）

ほかに、ゲームがモジュールごとに作る User Data\CPlusCrowdFilter\ModSettings.xml が残ります。中身は、モジュールが有効かどうか・最後に読んだ版・行動ウィンドウの大きさなどの窓の設定です（このファイルは丸ごと消してかまいません）。

キャラクターの設定のファイルは、ほかの UI の設定と同じファイルなので、手で書き換えるのはおすすめしません。書き換えるなら、ゲームを閉じてから、ファイルをコピーしたうえで行ってください。

8. 注意点・細かい仕様

  • オブハン フィルタと自動で拾う機能: CLifeUI の、オブハンの付いたアイテムを拾う機能は、ON の間はアイテムの札が出ないので拾いません。拾うときは OFF にしてください。
  • ダメージの色の判定: 名前の色は、ゲームが持っている相手の情報から読みます。まだ読めていない相手のダメージは出します。
  • 処理の重さ: 各フィルターは、ダメージの数字・オブハン・頭上の文が出るときに、出すかどうかを決めるだけです。自分の矢印は ON の間だけ 2 秒ごとに付け直し、OFF の間は何もしません。
  • うまく動かないとき: かぶせる相手の関数が見つからないときは、チャットに CPlusCrowdFilter : hook missing (…) と出て、その機能は働きません（ゲームのパブリッシュで標準の UI が変わったときなど）。フィルターの判定の途中でエラーが出たときは、隠さずにそのまま出し、チャットに 1 回だけ知らせます。
  • ほかの改造との重なり: CLifeUI を自分で変えているときや、同じ標準の関数を書き換えるほかの改造を一緒に入れているときは、「しくみ」の「CLifeUI を自分で変えているとき」を見てください。
